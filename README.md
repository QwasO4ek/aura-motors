# 🚗 AURA MOTORS — Премиальный автосалон

Минималистичный веб-сайт автосалона класса «люкс», разработанный в концепции **«Quiet Luxury»** (по стандартам *Porsche, Polestar, Genesis, Lucid*).

---

## 🚀 Деплой на Render (Инструкция)

Сайт полностью оптимизирован для мгновенного бесплатного развёртывания на платформе [Render.com](https://render.com).

### Способ 1: Как Static Site (Рекомендуется — бесплатно, 0 сек задержки)

1. Создайте новый репозиторий на [GitHub](https://github.com/new) или [GitLab](https://gitlab.com).
2. Загрузите файлы этого проекта в ваш репозиторий:
   ```bash
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/<ВАШ_РЕПОЗИТОРИЙ>.git
   git push -u origin main
   ```
3. Войдите в панель [Render Dashboard](https://dashboard.render.com).
4. Нажмите кнопку **«New +»** в правом верхнем углу и выберите **«Static Site»**.
5. Подключите ваш репозиторий.
6. Заполните параметры (Render обычно определит их автоматически из `render.yaml`):
   * **Name:** `aura-motors` (или любое желаемое имя)
   * **Branch:** `main`
   * **Build Command:** *(оставьте пустым)*
   * **Publish Directory:** `.` *(просто точка, корень проекта)*
7. Нажмите **«Create Static Site»**. 
   Через 30 секунд ваш сайт будет доступен по ссылке вида `https://aura-motors.onrender.com`.

---

### Способ 2: Через Render Blueprints (Автоматически)

В проект уже добавлен готовый файл конфигурации [`render.yaml`](./render.yaml).

1. В панели Render перейдите в раздел **«Blueprints»**.
2. Нажмите **«New Blueprint Instance»**.
3. Выберите репозиторий проекта.
4. Render автоматически считает файл `render.yaml` и настроит сервис за один клик.

---

### Способ 3: Как Web Service (Node.js)

Если вы хотите запустить проект через Node.js сервер ([`serve.js`](./serve.js)):
1. В Render выберите **«New +»** → **«Web Service»**.
2. Укажите:
   * **Runtime:** `Node`
   * **Build Command:** *(оставьте пустым или `npm install`)*
   * **Start Command:** `npm start` (или `node serve.js`)
   * **Plan:** Free

---

## 💻 Локальный запуск

1. **Без сервера:** Просто откройте `index.html` двойным кликом в любом браузере.
2. **С локальным сервером:**
   * На Windows: дважды кликните по [`start.bat`](./start.bat).
   * Через терминал:
     ```bash
     npm start
     # или
     node serve.js
     ```
   Сервер запустится по адресу: `http://localhost:3000`

## 🛠 Особенности и функционал

* **Каталог суперкаров и электрокаров:** Porsche 911 GT3 RS, Taycan Turbo S, Mercedes-AMG GT, BMW M8, Range Rover SV, Zeekr 001 FR, Audi RS e-tron GT, Aston Martin DB12.
* **Живые фильтры и поиск:** мгновенная фильтрация без перезагрузки страницы по кузовам, маркам, мощности и наличию.
* **Интерактивный Quick View Modal:** детальные технические характеристики, галерея ракурсов и комплектация.
* **Кредитный и Trade-In калькулятор:** расчёт аннуитетного платежа в реальном времени с выгодой до 500 000 ₽ при сдаче авто.
* **Система «Избранное»:** сохранение понравившихся автомобилей в `localStorage` и расчёт суммарной стоимости.
* **Запись на тест-драйв:** удобная форма с автоматической синхронизацией выбранного авто.
* **Адаптивный дизайн:** безупречный вид на смартфонах, планшетах и мониторах 4K.
